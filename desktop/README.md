# EyedOptimizer (desktop)

App Electron + React (Vite): monitor del PC, overlay OSD en juegos, Discord Rich Presence y utilidades.

## Desarrollo

```powershell
npm install
npm run dev
```

## Build Windows

```powershell
npm run build
npx electron-builder --win dir
```

Salida: `release/win-unpacked/EyedOptimizer.exe`
